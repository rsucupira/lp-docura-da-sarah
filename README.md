## Política de preços

A página inicial não fixa preços. Cada produto direciona para o WhatsApp com uma mensagem pronta para consultar:

- disponibilidade;
- valor atual;
- quantidade;
- prazo;
- retirada ou entrega.

Isso evita que a landing page fique desatualizada quando preços ou promoções mudarem.

## Publicação no GitHub Pages

No GitHub:

1. Abra **Settings**.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve.
